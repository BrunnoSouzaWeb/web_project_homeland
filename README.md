# Tripleten web_project_homeland.

This responsive web page project was developed as part of the TripleTen Bootcamp (Sprints 5 and 6) to assess foundational knowledge of responsive web design.

The project was based on Figma design specifications and includes layouts for different screen sizes:

* 1280px (desktop)
* 768px (tablet)
* 320px (mobile)

### Key concepts applied

* Responsive web design using media queries
* Mobile-first layout adaptation
* Breakpoint strategy for different devices
* Pixel-perfect implementation based on Figma design

### Breakpoints strategy

* 320px to 600px — mobile devices
* 600px to 900px — tablets
* 900px and above — desktop screens

This project demonstrates foundational skills in responsive layout development and design specifications.
